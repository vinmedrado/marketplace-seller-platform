# Frontend

Interface web do Marketplace Seller Platform.

## Visão geral

React + Vite + TypeScript + TailwindCSS + Framer Motion para a experiência privada do produto.

## Escopo

- landing page comercial;
- login;
- dashboard;
- telas principais do fluxo operacional;
- navegação entre áreas privadas.

## Como executar

```bash
cd frontend
npm install
npm run dev
```
